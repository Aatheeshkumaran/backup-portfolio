# Aatheesh Kumaran — Portfolio

A responsive React portfolio with a custom Three.js hero scene, CSS-built project artwork, selected work, experience, education, skills, and contact links.

## Run locally

Requires Node.js 18 or newer.

On Windows, double-click `start.bat`. It opens the portfolio in your browser and starts the Vite server. Leave the terminal window open while viewing the site.

Or start it manually from this folder:

```bash
npm install
npm run dev
```

Create a production build with `npm run build` and preview it with `npm run preview`.

The resume is served from `public/Aatheesh-Kumaran-Resume.pdf`.

Do not open `index.html` directly from File Explorer. This is a React/Vite app, so the browser must load it through the Vite server; opening the HTML file directly can show a blank page.
